# Owl Tower OS deployment snapshot

This repository is a historical static deployment snapshot. It is **not** the
source of truth for the current production portal, so asset names or commit dates
here must not be used to infer what is live.

- Canonical application source: [noctevusapp-a11y/owl-tower-os](https://github.com/noctevusapp-a11y/owl-tower-os)
- Production portal: [owl-tower-os-codex.noctevusapp.chatgpt.site](https://owl-tower-os-codex.noctevusapp.chatgpt.site/)
- Live release provenance: [build-info.json](https://owl-tower-os-codex.noctevusapp.chatgpt.site/build-info.json)

Each new production build publishes `build-info.json` with its exact canonical
source commit. Release and rollback instructions live in
`docs/DEPLOYMENT.md` in the canonical source repository.
